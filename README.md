# Circle of Leaders

A Next.js event website for Circle of Leaders, featuring upcoming finance leadership gatherings and an invitation request form backed by MongoDB.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Set `MONGODBURI` in your local `.env` file to enable invitation submissions. Environment files are excluded from Git.

## Commands

- `npm run dev` starts the development server.
- `npm run typecheck` checks TypeScript.
- `npm run build` creates the production build.
- `npm start` serves the production build.
